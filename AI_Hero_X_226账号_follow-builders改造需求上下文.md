# AI Hero X 账号监听系统设计上下文

## 目标

基于 follow-builders 项目进行二次开发，构建一个面向 AI
前沿实践的信息监听系统。

核心目标：

-   监听全球 AI 顶尖研究员、工程师、CEO、AI Builder 的
    X（Twitter）动态。
-   重点筛选：
    -   AI Coding
    -   Claude Code / Codex / Cursor
    -   Agent
    -   Multi-Agent
    -   Skills
    -   Prompt Engineering
    -   Context Engineering
    -   Evals
    -   RAG
    -   AI 工程实践
    -   AI 使用技巧
    -   AI 踩坑复盘

输出：

-   每日 AI 实战精选
-   中文总结
-   公众号文章素材
